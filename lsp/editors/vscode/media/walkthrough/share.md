# Export a report or convert formats

Three commands help you share a model.

- **Export Model Report** writes a Markdown report to a file you choose, then opens its preview. It covers statistics, objectives, constraints, non-default bounds, variable types and findings by category.
- **Convert to MPS** writes an `.mps` file next to the LP file.
- **Convert from MPS** reads the active MPS file and opens the LP text in a new unsaved editor, so nothing is overwritten.

Run any of them from the Command Palette by typing `LP:`.
