# Browse the model

The Model Explorer lists objectives, constraints and variables, grouped by type, with counts beside each group.

- Expand a constraint to see its coefficients.
- Expand a variable to see the rows that use it.
- Click any entry to jump to its source.
- Use the filter button in the view toolbar to search by name.

Open it from the LP activity bar, or press `Shift+Alt+M` (`Cmd+Alt+M` on macOS) in an LP editor.

The view needs a language server that advertises `lp/model`.
