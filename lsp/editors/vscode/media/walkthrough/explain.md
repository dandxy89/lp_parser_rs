# Explain a constraint

*LP: Explain Constraint* describes a constraint in the model's own terms: its terms, bounds, activity range, related rows and any diagnostics that mention it.

Place the cursor on a constraint name, then run the command. If the cursor is not on a constraint, you can pick one from a list.

Shortcut: `Shift+Alt+E` (`Cmd+Alt+E` on macOS) in an LP editor.

*LP: Explain Variable* does the same for a variable.
